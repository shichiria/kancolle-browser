# KanColle Browser v0.5.3

## 主な変更

- イベント攻略タブに「推奨編成」と、所持艦・所持装備を反映した編成リンクを追加
- 艦娘・装備の補正、基地航空隊の行動半径、装備の所持数と改修値を考慮する編成選択を改善
- イベントで使用する装備を改修タブで強調表示
- ロック中を含む所持数、改修値別内訳、改修元装備数、消費装備数を改修タブに表示
- 装備・資材が揃っている改修の判定と、改修実行後の表示更新を改善
- 明石の改修工廠データを再精査し、開発資材・改修資材・消費装備・特殊資材・曜日・更新先を更新
- イベント編成と改修データの監査・同期・差分レポート用スクリプトを追加
- 戦闘・遠征・通知・Drive同期などの安定性を改善
