# KanColle UI 操作領域マップ

ゲーム画面は 1200x720 (物理ピクセル)。座標はコントロールバー (28px) を除いたゲームcanvas内の相対位置。

> このマップの更新手順は [SPEC/action-analysis.md](../SPEC/action-analysis.md) を参照。`action_logs` から画面ごとのクリック座標と API 相関を解析し、新規領域を追記する。

## 画面判定

各画面はヘッダー領域のテキストで判別する（左上アイコンは回転アニメーションのため不可）。

| 画面 | ヘッダーテキスト | 位置 (概算) |
|------|-------------|----------|
| 母港 | なし（メニューアイコンが並ぶ） | - |
| 編成 | 「艦船選択」 | x≈90-200, y≈90 |
| 編成-艦船選択 | 「艦船選択」（右半分に艦娘リスト表示） | x≈90-200, y≈90 + 右パネル存在 |
| 編成-変更確認 | 「艦船選択」+「変更確認」 | 右下に「変更」ボタン |
| 補給 | 「艦船選択」+「燃料・弾薬の補給」 | x≈650, y≈90 |
| 入渠 | 「ドック選択」+「艦船選択」 | x≈90-200, y≈90 |
| 遠征選択 | 「遠征選択」+「遠征詳細」 | x≈90-200, y≈90 |
| 工廠 | 「ドック用途選択」+「現在の建造状況」 | x≈90-200, y≈90 |
| 工廠-開発 | 「開発資材投入」 | x≈90, y≈90 |
| 任務 | 「任務一覧」 | x≈90-200, y≈90 |
| 装備GET | 六角形背景 + 「GET!」 | 右下 x≈1050, y≈600 |
| 艦娘GET | 六角形背景 + 「GET!」+ 艦娘名 | 左下にテキスト |
| 出撃選択 | 「出撃選択」 | x≈90-200, y≈90 |
| 遠征結果 | 「海上護衛任務」等の遠征名 + 「獲得ボーナス」 | 中央上部 |
| 遠征-艦隊選択 | 「遠征選択」+「遠征詳細」+「艦隊選択」+「艦隊戦力分析」 | 右半分に艦隊パネル |
| 遠征-決定後 | 「遠征選択」+「遠征詳細」+「遠征中止/帰還命令」 | 右下に中止ボタン |
| 改装 | 「艦船選択」+「艦船ステータス」 | x≈90-200, y≈90 + 右に艦娘立ち絵 |
| 出撃マップ | 海域名（「鎮守府近海」等）+ マップ画面 | 上部中央に海域名、コンパス表示 |
| 陣形選択 | 「陣形を選択してください。」 | 下部中央テキスト + 4つの陣形ボタン |
| 戦果報告 | 「戦果報告」+ 海域名 + 勝利ランク | 左上「戦果報告」、中央に勝利表示 |
| 進撃/撤退選択 | 「進撃」「撤退」ボタン | マップ上に2つのボタン |
| アイテム使用 | 「使用可能」+「使用」ボタン + 対象艦リスト | 右中央に使用ボタン、下部に艦カード |
| 編成-プリセット選択 | 「編成プリセット」+ 行リスト | 中央大パネル、右端に閉じる |
| 改装-装備プリセット選択 | 「装備プリセット」+ カード | 下部にプリセットカード、右上に呼出/保存 |
| 装備交換 | 「装備交換」（slot_exchange_index 発火時） | 装備リスト+決定ボタン |
| 演習-相手詳細 | 演習艦隊リスト + 艦娘ステータス | 右側に決定/出撃ボタン |
| 解体 | 「解体」+ 艦娘チェックリスト | 左に艦娘リスト、右下に決定 |

```

  x≈700-799, y≈400-599: プリセット行 (展開・選択)
```

## API を発行しない UI アクション

以下は純クライアント処理 (API を伴わない画面内操作) で、クリック記録のみで検出する必要がある。

### 連打系（演出スキップ）
- **出撃マップ/進撃中**: (650-700, 300-350) を反復クリック。セル移動アニメ送り。
- **戦闘中**: 画面中央〜下段の広域連打。戦闘アニメ各フェーズのスキップ。
- **戦果報告**: (350-450, 300-450) 付近の反復クリック。MVP/戦果演出送り。
- **演習結果**: (300-450, 300-500) の反復クリック。

これらは画面単位では意味を持たず、`battle_advance` / `map_advance` / `result_advance` の単一カテゴリで吸収する方針が妥当。

### タブ / パネル切替 (API 無し)
- **編成-艦船選択**: 艦種フィルタ横帯 (x≈550-1000, y≈100-150) — 選択状態が変わるだけで API 発火なし。実選択確定は別 API (`ship_deck` 等)。
- **編成-プリセット選択**: プリセット行展開 (x≈700-799, y≈400-599) — 展開のみ、選択確定は `preset_select` API。
- **改装-装備画面**: 装備スロットのプレビュー選択。
- **任務**: フィルタラジオボタンの選択（フィルタ変更は API 無しで UI のみの場合あり）。
- **設定系**: 各画面右上/右下の閉じる・モード切替ボタン (1100-1199, 150-250) — 多くが API 無し。

### 画面外クリック（ウィンドウ枠操作）
`y<0` / `y>720` / `x>1200` に着弾したクリックは、タイトルバー、リサイズ、ウィンドウ外操作。2026-04-23 のログで 24 件観測。
- 典型: `(1189, -15)`, `(777, -15)`, `(848, -26)`, `(940, 754)` 等
- ui_event の判定対象外にすべき（ガード条件を追加する余地）。

## 座標精度について

- 上記座標はスクショ目視による概算値
- ユーザーのクリック位置にはブレがある（同じボタンでも ±15px 程度）
- 領域境界は余裕を持たせて定義する必要あり
- 操作ログ蓄積により座標を統計的に補正していく
