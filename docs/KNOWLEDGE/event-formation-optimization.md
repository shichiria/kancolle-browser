# イベント編成の装備最適化

最終更新: 2026-07-29
基準例: 期間限定海域 E3-3、[ぜかましねっと攻略記事](https://zekamashi.net/202607-event/urushiihakuchi-hankou-4/)、[制空権シミュレータ編成](https://kc.noro6.net/s/fQr6)

## 「最強装備」の定義

装備単体の表示ステータス順ではなく、次の優先順位で判定する。

1. **ハード制約**: 所持している実インスタンスだけを1回ずつ使う。装備可能艦・増設可否・基地半径を満たす。
2. **元編成の機能**: 特効、特殊攻撃、CI構成、夜偵、対空、基地防空などの役割を壊さない。
3. **敵への有効性**: 敵艦種、陸上型か水上艦か、PT、対空、装甲、随伴構成を考慮する。
4. **道中とボスの成立条件**: 基地到達、制空状態、索敵、対空CIなどを満たす。
5. **装備・艦娘・組み合わせ補正**: 改修値、艦型補正、装備シナジーを含めた実効値で比較する。
6. **同条件内の強さ**: 火力、雷装、命中、回避、撃墜耐性などを目的に合わせて比較する。

異なる役割の装備を「同じカテゴリ」という理由だけで置換しない。特に、零式小型水上機、特四式内火艇、後期型潜水艦魚雷、ロケット局戦は役割を保った候補だけで置換する。

## E3-3で固定すべき前提

### 敵と基地航空隊

- ボスXマスの必要戦闘行動半径は **7**。元編成の出撃基地は、第1が半径7以上、第2も半径7以上で成立している。
- アレンジ後も各陸攻の半径を元装備未満にしない。これは偵察機による延長を再計算しない現段階での保守的な不変条件。
- ボス本隊は環礁空母泊地棲姫-壊、空母ヲ級flagship、輸送ワ級elite、随伴は軽巡ツ級elite、後期型駆逐艦、PT小鬼群。ボス名に「泊地」があっても通常の陸上型として一律に爆装評価してはいけない。
- 軽巡・駆逐の割合が大きいため、B-25の艦種別補正と命中補正が働きやすい。一方でB-25には撃墜回避がないので、軽巡ツ級eliteを含む敵対空も別軸で評価する。

### B-25と陸攻

[B-25 Wiki「ゲームにおいて」](https://wikiwiki.jp/kancolle/B-25)によれば、B-25は水上艦にスキップボミングを行い、表示雷装8をそのまま使わない。目安となる実効雷装は駆逐約19.6、軽巡約18、重巡約16、軽空母・戦艦・輸送艦約11.5～12で、駆逐・軽巡には命中補正もあるとされる。

したがってE3-3では、基本の一式陸攻（雷装10）をB-25より上に置かない。比較は以下を分ける。

| 装備 | 主な特徴 | E3-3での扱い |
|---|---|---|
| B-25 | 半径7、対小型水上艦の艦種別補正、高爆装、撃墜回避なし | 随伴処理を重く評価。基本一式陸攻への置換は禁止ではなく、期待効率でB-25を優先 |
| 一式陸攻(野中隊) | 半径9、弱い撃墜回避、改修可能 | 高対空マスでの生残と半径、改修込み雷装を評価 |
| 銀河 | 半径9、雷装14の汎用陸攻、撃墜回避なし | 大型水上艦への汎用打点 |
| 銀河(江草隊) | 半径8、雷装・爆装15、命中3、弱い撃墜回避 | 汎用火力・命中・生残の総合評価 |

参照: [一式陸攻(野中隊)](https://wikiwiki.jp/kancolle/一式陸攻(野中隊))、[銀河](https://wikiwiki.jp/kancolle/銀河)、[銀河(江草隊)](https://wikiwiki.jp/kancolle/銀河(江草隊))

### 潜水艦の特殊装備

- [零式小型水上機](https://wikiwiki.jp/kancolle/零式小型水上機)は、潜水空母で雷装・索敵・命中・回避の装備ボーナスを持つ。★0でも回避+5を含み、改修段階で雷装・命中・回避・索敵が追加される。E3-3ではさらに潜水艦搭載時のイベント特効があるため、夜偵として優秀でもWalrusへ置換しない。
- [零式小型水上機(熟練)](https://wikiwiki.jp/kancolle/零式小型水上機(熟練))は基礎値と追加補正が強い。同じ「零式小型水上機」役の上位候補として比較する。
- [特四式内火艇](https://wikiwiki.jp/kancolle/特四式内火艇) / 特四式内火艇改は環礁ボスで専用の先制雷撃を行う。1隻2個まで攻撃回数が増え、通常装備との単純な対地値比較はできない。
- 特四式内火艇装備艦は通常の夜戦魚雷CIを行わない。非内火艇艦は後期型潜水艦魚雷と潜水艦電探の組み合わせを保ち、最大倍率の夜戦CIを狙う。
- 後期型潜水艦搭載電探&逆探、後期型電探&逆探+シュノーケル装備は、単体ステータスだけでなく後期型魚雷とのCI成立を優先する。

### 防空

秋水、試製 秋水、Me163Bは高高度爆撃へのロケット戦闘機補正を担う。基地防空枠ではこの役割を維持し、通常局戦・陸戦を表示対空だけで代用しない。

参照: [秋水](https://wikiwiki.jp/kancolle/秋水)、[試製 秋水](https://wikiwiki.jp/kancolle/試製%20秋水)、[Me163B](https://wikiwiki.jp/kancolle/Me163B)

## 改修値（★）の扱い

改修値は装備インスタンスごとに保持し、同一装備を所持数以上に複製しない。比較時は次の2種類を両方加える。

1. 装備カテゴリ共通の改修効果（例: 主砲火力、魚雷雷装、航空機の対空・雷装・索敵）。
2. kc-web `ItemBonus.ts` 由来の艦娘・艦型・装備組み合わせ・★閾値ボーナス。

例:

- 零式小型水上機は★1/2/3/5/8/10で潜水空母向けボーナスが段階的に増える。
- 後期型潜水艦魚雷は改修雷装を持つ。
- 水上戦闘機は★による制空値が編成成立に直結する。
- 8inch三連装砲 Mk.9 mod.2★9、61cm三連装(酸素)魚雷後期型の高改修は、未改修の同カテゴリ装備より表示値だけでは判断できない。

現実装は共通改修式とkc-web装備ボーナスを評価する。ただし、イベント固有倍率やB-25の艦種別攻撃値のようにkc-webの通常装備ボーナスへ含まれない効果は、イベント・装備固有ルールとして別に管理する。

## 実装上の不変条件

- 所持装備は `instance_id` 単位で割り当て、一つの装備を二つのスロットへ割り当てない。
- 出撃基地の候補装備半径は元スロットの装備半径以上。
- B-25は攻撃対象の敵艦種から実効雷装を計算する。
- 零式小型水上機、特四式内火艇、後期型潜水艦魚雷、ロケット局戦は意味的な装備群を維持する。
- 置換不能なときは別役割の装備で埋めず空欄にし、「不足」として利用者に示す。

## 未確定・今後の評価項目

- イベント特効値は検証中の値が更新され得る。イベント識別子と確認日を付けて管理する。
- 基地偵察機による半径延長を含む「基地全体の実効半径」は未実装。現状は各スロットで元半径を下回らない保守的判定。
- 敵対空砲火による期待残機、熟練度、制空状態を含む基地航空隊の完全な期待ダメージ計算は今後の課題。
- 夜戦CI発動率、特殊攻撃回数、PT命中を統一した編成全体の目的関数は今後の課題。現段階では役割破壊をハード制約で防ぐ。
